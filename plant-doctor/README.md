# 🌿 דוקטור צמחים

אפליקציית ווב לנייד: מצלמים צמח, עונים על כמה שאלות, ומקבלים זיהוי, אבחון, תוכנית טיפול ותנאים אידיאליים, מותאמים למזג האוויר במיקום שלך.

## מה עובד היום (שלב 1)

- צילום מודרך של עד 4 תמונות. התמונות מוקטנות ל-1600px בטלפון לפני השליחה, ונתוני המיקום (GPS) שבתוך התמונה נמחקים.
- שאלון קצר עם כפתורי בחירה מהירה, ומיקום לפי GPS או שם עיר (המיקום נשמר בטלפון).
- אבחון שמצליב שלושה מקורות במקביל:
  - **Claude** (Anthropic) מנתח את התמונות ומחזיר תשובה במבנה קבוע, שנבדק לפני שמוצג.
  - **Pl@ntNet** מזהה את הצמח מול מאגר תצפיות עולמי.
  - **Open-Meteo** נותן מזג אוויר עכשווי ותחזית ל-7 ימים.
- אם מקור אחד נופל, האבחון ממשיך בלעדיו ומציין מה היה חסר.
- כשהביטחון באבחון נמוך מ-70%, האפליקציה שואלת עד 3 שאלות המשך ואז מאבחנת שוב.
- כשהזיהוי של Claude ושל Pl@ntNet לא מסכים, מוצגות שתי האפשרויות ואתה בוחר.
- כפתור "בדיקה מעמיקה" מריץ את המודל החזק יותר (Opus) למקרים לא ברורים.
- מסך התהליך מראה כל שלב בזמן אמת, ובסוף מוצגים זמן הבדיקה והעלות המשוערת.
- עברית מלאה מימין לשמאל, מצב כהה ובהיר לפי הטלפון.

**עוד לא נבנה:** הגינה שלי, היסטוריה, תזכורות, התקנה למסך הבית ומסך הגדרות. אלה שלבים 2 עד 4.

## מפתחות שצריך (פעם אחת)

### 1. Anthropic API (חובה, בתשלום לפי שימוש)

1. נכנסים ל-[console.anthropic.com](https://console.anthropic.com) ונרשמים.
2. ב-**Billing** מטעינים קרדיט. 5$ מספיקים להרבה בדיקות.
3. ב-**API Keys** לוחצים **Create Key**, ומעתיקים את המפתח (מתחיל ב-`sk-ant-`). הוא מוצג פעם אחת בלבד.

עלות משוערת (לפי חישוב, עוד לא נמדד): כ-3 עד 7 סנט לאבחון רגיל, וכ-10 עד 15 סנט לבדיקה מעמיקה. העלות המדויקת של כל בדיקה מוצגת בתחתית מסך התוצאה.

### 2. Pl@ntNet (מומלץ, חינמי)

1. נכנסים ל-[my.plantnet.org](https://my.plantnet.org) ונרשמים.
2. בעמוד **Your API key** מעתיקים את המפתח.
3. אם יש אפשרות להגביל את המפתח לדומיין מסוים, לא מגבילים. הקריאות יוצאות מהשרת, לא מהדפדפן.

המכסה החינמית היא 500 זיהויים ביום. בלי המפתח האפליקציה עדיין עובדת, ומזהה רק לפי התמונות.

### 3. מזג אוויר

לא צריך מפתח. Open-Meteo חינמי.

## הרצה מקומית

```bash
cd plant-doctor
npm install
cp .env.example .env.local   # ממלאים את המפתחות בקובץ
npm run dev
```

פותחים את http://localhost:3000. כדי לבדוק בטלפון באותה רשת: `npm run dev -- -H 0.0.0.0`, ונכנסים לכתובת ה-IP של המחשב. איתור המיקום לפי GPS עובד רק ב-HTTPS, אז בבדיקה מקומית בטלפון כותבים שם עיר.

## העלאה ל-Vercel

1. נכנסים ל-[vercel.com](https://vercel.com) עם חשבון GitHub ולוחצים **Add New → Project**.
2. בוחרים את הריפו, ובשדה **Root Directory** בוחרים `plant-doctor`.
3. ב-**Environment Variables** מוסיפים את `ANTHROPIC_API_KEY` ואת `PLANTNET_API_KEY`.
4. לוחצים **Deploy**. אחרי דקה-שתיים מקבלים כתובת HTTPS, ופותחים אותה בטלפון.

היעד הוא אבחון תוך פחות מ-20 שניות; את הזמן בפועל רואים בתחתית מסך התוצאה. הנתיב `/api/diagnose` מוגדר לרוץ עד 60 שניות.

## הגדרות נוספות

כל ההגדרות מתועדות ב-[`.env.example`](.env.example):

| משתנה | ברירת מחדל | מה זה |
|---|---|---|
| `CLAUDE_MODEL` | `claude-sonnet-5-5` | המודל לאבחון רגיל: מהיר וזול |
| `CLAUDE_DEEP_MODEL` | `claude-opus-5-5` | המודל לבדיקה מעמיקה |
| `CLAUDE_EFFORT` | `medium` | עומק החשיבה באבחון רגיל: `low`, `medium` או `high` |
| `DIAGNOSE_RATE_LIMIT` | `15` | מקסימום אבחונים ב-10 דקות מאותה כתובת |

## מבנה הקוד

```
app/
  page.tsx                  מסך הבית
  diagnose/DiagnoseFlow.tsx  התהליך: צילום → שאלון → תוצאה
  api/diagnose/route.ts      השרת: מריץ את המקורות ומזרים התקדמות
components/                 צילום, שאלון, מיקום, התקדמות, תוצאה, שאלות המשך
lib/
  schema.ts                 מבנה התשובה שמחייב את Claude
  systemPrompt.ts           ההנחיות ל-Claude
  adapter.ts                הגבלת זמן, ניסיון חוזר וגיבוי לכל מקור חיצוני
  sources/                  claude.ts, plantnet.ts, openMeteo.ts
  rateLimit.ts, cost.ts     הגבלת קצב והערכת עלות
```

המפתחות נקראים רק בצד השרת. שום מפתח לא נשלח לדפדפן.

## פרטיות

- התמונות לא נשמרות בשום מקום. הן נשלחות ל-Anthropic ול-Pl@ntNet לצורך האבחון בלבד.
- המיקום מעוגל לכקילומטר אחד לפני שהוא נשלח לשירות מזג האוויר.
