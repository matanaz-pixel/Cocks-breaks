# חמש גרסאות לאתר יועצת שינה

פותחים את `sleep-landing/index.html` בדפדפן ובוחרים גרסה.

| קובץ | סגנון |
|---|---|
| v1-moon.html | ירח: כחול לילה וסריף |
| v2-dawn.html | שחר: צבעי אדמה וקשתות |
| v3-minimal.html | מינימל: לבן, ניווט צד |
| v4-rainbow.html | קשת: פסטלים ובנטו |
| v5-forest.html | יוקרה: ירוק יער וזהב |

## החלפת תוכן
כל הטקסטים, הטלפון, הקישורים וההמלצות נמצאים ב-`src/content.py`.
אחרי עריכה מריצים `python3 sleep-landing/src/build.py` (דורש `pip install jinja2`) והחמש גרסאות מתעדכנות יחד.
ההמלצות מסומנות "דוגמה". כשמחליפים בהמלצות אמיתיות מוחקים את `"sample": True`.
