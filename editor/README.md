# עורך האתר

הקובץ `site-editor.html` הוא כל המערכת. לא צריך להתקין כלום ולא צריך אינטרנט.

## שימוש
1. לחיצה כפולה על `site-editor.html`. מומלץ לפתוח ב-Chrome או ב-Edge.
2. עוברים בין הלשוניות ועורכים. התצוגה בצד מתעדכנת מיד, ואפשר לעבור בין "מחשב" ל"טלפון".
3. הכול נשמר אוטומטית בדפדפן. מדי פעם לוחצים על "שמירת גיבוי" ושומרים את הקובץ במקום בטוח.
4. בסוף נכנסים ללשונית "פרסום", בודקים שלא נשאר דבר זמני, מורידים את האתר כקובץ ZIP ומעלים אותו.

## מה אפשר לערוך
- כל הטקסטים בדף הבית ובארבעת עמודי השירות, כולל רשימות, שאלות נפוצות ושלבים (אפשר להוסיף, למחוק ולסדר מחדש).
- פרטי קשר וקישורים לרשתות.
- שש תמונות: תמונה ראשית, תמונה אישית ותמונה לכל שירות. אפשר להוסיף אותן בשלוש דרכים: לחיצה על מסגרת התמונה בתצוגה, בלשונית של אותו עמוד, או בלשונית "תמונות".
- המלצות לכל שירות, ומה מוצג בדף הבית.

## מה לא נערך כאן
הוספת עמוד שירות חדש, שינוי צבעים ושינוי מבנה העמודים. אלה דורשים שינוי בקוד.

## חשוב לדעת
- העבודה נשמרת בדפדפן ובמחשב הזה בלבד. ניקוי נתוני דפדפן או מעבר מחשב ימחקו אותה, ולכן צריך גיבוי.
- "פתיחת גיבוי" טוענת קובץ גיבוי שנשמר קודם, ומחליפה את מה שיש עכשיו.
- "ביטול פעולה אחרונה" מחזיר מחיקות והחלפות תמונה. בתוך שדה טקסט אפשר להשתמש ב-Ctrl+Z.

## למפתחים
העורך נבנה מהקבצים ב-`site/src`. אחרי שינוי בקוד או ב-`site/src/content.json`: `cd site && npm run build`.
